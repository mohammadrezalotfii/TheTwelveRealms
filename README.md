# LoveLetter — دوازده جهان، یک عسل

یک داستان تصویری اسلایدی، راست‌به‌چپ و موبایل‌محور که بدون بک‌اند یا وابستگی خارجی اجرا می‌شود.

فونت‌های رابط از مجموعه‌ی محلی پروژه بارگذاری می‌شوند: **Peyda** برای متن و **Pinar** برای تیترها.

## اجرا

فایل `index.html` را مستقیماً در مرورگر باز کنید. برای تستی نزدیک‌تر به انتشار، پوشه را با هر وب‌سرور استاتیک محلی باز کنید.

## تست خودکار

در زمان اجرای وب‌سرور، فایل `tests.html` را باز کنید. این صفحه ۱۷ آزمون مرورگری برای اسلایدر، تم‌ها، تصاویر، متن، لمس، اسکرول، فونت‌ها و دسترس‌پذیری اجرا می‌کند.

## شخصی‌سازی داستان‌ها

- تمام عنوان‌ها و متن فصل‌ها در فایل `stories.js` قرار دارند.
- برای هر فصل، `title`، آرایه‌ی `paragraphs` و `punchline` را با متن واقعی رضا جایگزین کنید.
- ترتیب فصل‌ها با جابه‌جاکردن آبجکت‌ها در همان آرایه تغییر می‌کند.

هیچ خاطره‌ی مشترکی در نسخه‌ی اولیه اختراع نشده است.
